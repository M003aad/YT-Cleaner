## [1.0.0] - 2026-10-26

### Added
- Initial release of the browser extension.
- Original title restoration for YouTube videos using the oEmbed endpoint.
- Toggle to disable original-title replacement without reloading the extension.
- Visual cleanup options for notifications, Shorts, comments, related videos, and playlists.
- Persistent extension settings via `chrome.storage.sync`.
