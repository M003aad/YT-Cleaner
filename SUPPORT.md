# Support

For documentation and current instructions, please start with the [README](./README.md).

If you need help:

- check the GitHub issue tracker for existing reports;
- search for similar troubleshooting topics in the repository discussions or issues;
- open a new issue using the bug report template if your problem is not already covered.

For vulnerability reports, follow the process in [SECURITY.md](./SECURITY.md).
